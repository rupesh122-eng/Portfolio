# Rupesh Thakur Portfolio

A responsive personal portfolio website built from scratch using only:
- HTML
- CSS
- JavaScript

## Files
- `index.html` — website structure/content
- `style.css` — responsive styling and layout
- `script.js` — mobile menu, theme toggle, scroll reveal and active navigation

## Before submitting
1. Replace the placeholder GitHub, LinkedIn and email links in `index.html`.
2. Add your real GitHub repository URLs to the three project cards.
3. If you have a professional photo, replace the `RT` profile placeholder with your image.
4. Open `index.html` in a browser and test every section and link.
5. Deploy the folder on Vercel.
